# I18N — Internationalization

Languages of the user interface and of the assistant. Background: ADR-0019.

## I18N-001: Externalized strings

- **Status:** implemented
- **Priority:** MUST
- **Phase:** 1
- **Verification:** design

Every user-facing string in clients MUST come from translation resources,
never from hard-coded text. Server responses carry stable codes that clients
translate (API-007).

## I18N-002: English and Italian

- **Status:** draft
- **Priority:** MUST
- **Phase:** 3
- **Verification:** review

The first release MUST ship complete English and Italian translations.

## I18N-003: Assistant language

- **Status:** draft
- **Priority:** SHOULD
- **Phase:** 1
- **Verification:** eval

The assistant SHOULD answer in the user's preferred language unless the user
writes in, or asks for, another one.
