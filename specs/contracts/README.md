# Contracts

Contracts are the parts of the system that outlive any particular
implementation (ADR-0003). Code may be regenerated; contracts change only
through `spec/*` pull requests.

| Contract | File (planned) | Enforced by |
|---|---|---|
| Public HTTP API | `openapi.yaml` | CI compares the OpenAPI document generated by the server with this file (API-002) |
| Database schema | `database.md` and the migrations | Design tests on the live schema: RLS, ownership columns, roles (TEN-002, TEN-003, TEN-004) |
| Sandbox driver API | `sandbox-driver.yaml` | Contract tests between control plane and driver (SBX-009) |
| On-disk formats | `formats.md` | Backup/restore and upgrade tests (OPS-005, OPS-006) |

No contract exists yet: they will be written in phase 0, before the code that
implements them.
